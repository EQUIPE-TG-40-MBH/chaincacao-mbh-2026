# 📖 Guide Utilisateur - ChainCacao

Bienvenue dans le guide d'utilisation de ChainCacao, la solution de traçabilité du cacao togolais conforme aux normes EUDR.

!Logo ChainCacao

## 👨‍🌾 1. Espace Agriculteur (Application Mobile)

### Enregistrer une récolte
1. Ouvrez l'application. Si vous préférez, activez l'assistance vocale (**Éwé** ou **Kabiyè**).
2. Saisissez le poids estimé de votre récolte (en kg).
3. Cliquez sur **"ENREGISTRER"**. Si vous êtes hors du périmètre, utilisez **"Capturer quand même"** pour valider votre position réelle.
4. Votre position GPS est automatiquement relevée pour prouver l'origine légale.
5. Un **Code QR** unique est généré. Présentez-le à votre coopérative.

## 🏭 2. Espace Coopérative (Dashboard Web)

### Valider un lot
1. Allez dans l'onglet **"Lots Reçus"**.
2. Scannez le QR code du producteur ou saisissez l'ID du lot.
3. Pesez physiquement le cacao et saisissez le **"Poids Vérifié"**.
4. Si le poids concorde, validez. Le statut passe en **"VALIDATED"** sur la blockchain.

### Fusionner des lots (Merge)
Pour préparer un grand conteneur, sélectionnez plusieurs petits lots validés et cliquez sur **"Fusionner"**. Cela crée un nouveau lot parent traçable jusqu'aux agriculteurs individuels.

## 🚢 3. Espace Exportateur

### Générer le certificat EUDR
1. Sélectionnez les lots prêts pour l'exportation vers l'Europe.
2. Cliquez sur **"Générer Certificat EUDR"**.
3. Le système vérifie la conformité géographique.
4. Téléchargez le PDF et envoyez-le à votre acheteur européen en un clic.

## 🇪🇺 4. Espace Importateur & Public

### Vérifier la traçabilité
1. Pas besoin de compte. Rendez-vous sur la page **Vérification Publique**.
2. Saisissez l'identifiant du lot ou scannez le QR code présent sur le sac.
3. Consultez instantanément :
   - Le nom du producteur et le village.
   - La preuve de transaction sur la blockchain Polygon.
   - La confirmation que le cacao ne provient pas d'une zone déforestée.
